
# Chuwa Project 1 – E-commerce Platform

## 🧾 Description
A full-stack e-commerce web application built during Chuwa America's fullstack training program (2025). This project simulates a modern online store with user authentication, product browsing, cart management, and admin control.

## 👨‍💻 My Contribution
I was responsible for multiple frontend and backend functionalities:
- Implemented user authentication with JWT (Sign In / Sign Up)
- Developed protected routes for admin users
- Built Create/Edit Product pages for admins
- Added out-of-stock check: disable "Add to Cart" and redirect to ErrorPage
- Improved user experience and routing with React Router

## 🛠️ Tech Stack
- Frontend: React, Redux, React Router
- Backend: Node.js, Express
- Database: MongoDB
- Auth: JWT
- Styling: Tailwind CSS
